# 玉衡 · Yuheng

> 让 Root 管理，也有东方美学。

玉衡（Yuheng）是一款基于 KernelSU 及白饭 KSU LKM 开源代码开展二次开发的 Android Root 管理器，采用东方美学作为品牌设计方向，致力于在保留 Root 管理能力的基础上，提供更细腻的视觉与交互体验。

**玉衡是独立的非官方衍生项目，不代表 KernelSU 或上游项目官方立场，也未获其官方背书。**

## 品牌与主题

| 主题 | 定位 | 视觉关键词 |
| --- | --- | --- |
| 青瓷雾 | 默认浅色主题 | 浅青釉、雾灰、柔和玉色，避免纯白大面积铺底 |
| 墨玉 | 默认深色主题 | 深青灰、墨色、低亮度玉绿，非简单反色 |
| 月白 | 规划中 | 冷灰、淡蓝白 |
| 暖玉 | 规划中 | 米杏、暖灰、温润玉色 |
| 黛紫 | 规划中 | 灰紫、烟紫、淡银 |
| 玄曜 | 规划中 | 深黑、曜石灰、冷银 |

品牌主张：**以玉为度，简而有序。**
