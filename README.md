# 玉衡 · Yuheng

> 让 Root 管理，也有东方美学。

玉衡（Yuheng）是一款基于 KernelSU 开源生态进行二次开发的 Android Root 管理器。项目以东方美学为设计理念，探索更精致的界面、更灵活的主题系统与更清晰的交互体验。

**玉衡是非官方衍生项目，与 KernelSU 官方及其他上游项目不存在隶属或背书关系。**

## 项目方向

- 保留并尊重上游 Root 授权、模块管理及安装能力。
- 建立统一的主题数据层，适配项目现有的 Material 与 Miuix 界面。
- 提供独立设计的浅色与深色主题。
- 优先保证稳定性、兼容性和可访问性，再逐步增加视觉效果。
- 对上游修改保持可追溯，明确记录来源、修改内容与许可证。

## 品牌与主题

| 主题 | 定位 | 视觉关键词 |
| --- | --- | --- |
| 青瓷雾 | 默认浅色 | 浅青釉、雾灰、柔和玉色 |
| 墨玉 | 默认深色 | 深青灰、墨色、低亮度玉绿 |
| 月白 | 浅色扩展 | 冷灰、淡蓝白 |
| 暖玉 | 浅色扩展 | 米杏、暖灰、温润玉色 |
| 黛紫 | 色彩扩展 | 灰紫、烟紫、淡银 |
| 玄曜 | AMOLED 扩展 | 深黑、曜石灰、冷银 |

## 开发状态

当前仓库用于建立玉衡的品牌与开发基线。正式 Android 工程源码、上游基线及可构建版本将在完成来源核对、许可证清点和工程迁移后逐步提交。

**当前尚未发布可安装 APK，也不代表 Root 功能已完成验证。**
