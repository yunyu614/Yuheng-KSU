# 玉衡视觉方向规范：东方未来科技美学

> 本规范取代此前偏向传统古画、文物、刺绣和水墨的五神兽素材方向。上述历史艺术作品不作为玉衡正式主视觉候选。

## 品牌视觉定位

玉衡的视觉方向为「东方未来科技美学」：以中国五神兽为核心识别符号，用现代高精度数字艺术、3D 材质和未来场景表达。整体应像高端系统工具的品牌视觉，而不是古风壁纸、手游宣传海报或赛博朋克霓虹拼贴。

## 明确禁止

- 不使用古画、文物照片、刺绣补子、书法、水墨画作为主视觉。
- 不使用低质量线稿、抽象几何图标、通用渐变光球冒充神兽。
- 不使用来源不明、无再分发授权或仅允许个人使用的图片。
- 不将网页图片 URL 作为运行时壁纸热链；最终素材必须本地打包。
- 不为了视觉装饰降低文字对比度、功能可读性或页面性能。

## 总体美术标准

- 主体：高辨识度、完整可读的神兽实体，优先精致 3D / 高质量数字雕塑 / 电影级概念艺术。
- 材质：玉石、磨砂陶瓷、拉丝金属、半透明晶体、釉面、细腻能量光效。
- 光照：电影级轮廓光、体积雾、柔和反射与真实阴影；控制高光，不做廉价爆闪。
- 场景：现代东方未来空间、数字山峦、粒子云海、能量水域、抽象但有空间层次的地貌。
- 构图：主体清晰，给标题、状态卡和导航留出干净负空间。
- 颜色：每个主题具有独立主色、辅助色、材质与环境氛围，不是单纯色相替换。
- 统一性：五套采用同一渲染语言、镜头逻辑、细节密度和光照品质。

## 交付规格

每套至少需要：
1. Hero：透明背景主体图，建议 1600px 以上长边，PNG/WebP。
2. Background：独立 9:16 或可裁切竖版场景图，建议 1440x2560 以上。
3. Ornament：可选的低对比度局部纹样或材质细节，避免重复平铺造成廉价感。
4. Preview：主题选择页专用裁切图，必须与该主题 Hero 对应。

最终集成时使用本地资源、按屏幕尺寸裁切、设置主题专属暗色遮罩和渐变保护文字区域；对 Bitmap 解码使用采样和缓存，避免大图直接全尺寸常驻内存。

## 验收标准

- 缩小到手机首页实际尺寸仍能一眼认出神兽。
- 不看主题名称，也能区分五套主题。
- 五套视觉品质、细节密度和构图完成度一致。
- 背景与主体相互匹配，不能出现主体和环境风格冲突。
- 页面信息仍是第一优先级，神兽视觉不能遮挡 Root 状态、设备信息和操作控件。
