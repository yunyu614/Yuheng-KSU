## 已否决或暂不采用的方向

- 古画、水墨、文物照片、刺绣补子、传统书画直接作为主视觉。
- 用户此前指出不匹配的 Gemini 生成候选图，以及未通过用户视觉验收的文件库候选。
- 抽象几何、低质量线稿、通用渐变光球或无法清晰辨认的神兽轮廓。
- 来源、具体文件授权或 APK 再分发权利无法确认的图片。
- 用设计稿或 UI mockup 冒充真实设备截图。

程序化 Canvas 神兽插画仅是开发期占位，不属于最终美术交付。没有确认的新素材前，不应将其包装成正式主视觉。

## 未来素材验收

每个主题至少需要透明主体图与独立竖版背景，且同时满足：

1. 神兽主体清晰、完整、有高质量实体感，手机实际尺寸仍能辨认。
2. 主体材质、光影和环境具有精细度，不呈现廉价手游海报或素材拼贴感。
3. 背景与主体属于同一视觉场景，为标题、Root 状态和导航保留干净负空间。
4. 五套采用一致的镜头语言、渲染品质和细节密度，但主色、材质和环境明确不同。
5. 适配亮色/暗色界面和不同屏幕比例，并进行压缩、解码采样、内存占用和真机可读性检查。
6. 每个文件单独核对生成来源或再分发许可，并随仓库记录来源和许可信息。
7. 用户确认视觉效果后才进入仓库和 APK。
