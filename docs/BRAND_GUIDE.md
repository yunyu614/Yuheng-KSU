# 玉衡品牌与界面基线

## 品牌定位

- 中文名：玉衡
- 英文名：Yuheng
- 产品定位：基于 KernelSU 开源生态的独立 Android Root 管理器衍生项目
- 品牌关键词：秩序、自由、雅致、温润、可靠
- 品牌短句：以玉为度，简而有序。
- 视觉方向：东方未来科技美学；以中国神兽意象为识别体系，以现代数字材质和清晰的信息设计表达。

## 视觉原则

1. 东方意象用于建立品牌辨识度，不把古画、文物、刺绣、书法或水墨直接堆叠到功能界面。
2. 浅色界面使用有层次的玉色、雾色和柔和容器，不以纯白作为大面积页面底色。
3. 深色模式独立定义背景、容器、边框和文字层级，不采用简单反色。
4. Root 状态、授权、模块和安装等关键任务优先于装饰；不同页面应保留各自的信息结构，不把所有页面改成同一套卡片堆叠。
5. 动效克制；避免持续动画和全屏实时模糊，优先保证滚动、导航和低端设备性能。
6. 不使用低质量线稿、抽象几何或通用渐变图形冒充神兽主视觉。
7. 所有外部素材必须核对具体文件的来源、许可和再分发权；没有确认授权的资源不得进入 APK。

## 昼夜与材质

- 支持跟随系统、浅色和深色模式；动态取色、AMOLED 等选项以应用实际界面和设置项为准。
- 页面背景、卡片、弹层和状态栏应使用一致的主题令牌。
- 悬浮底栏与玻璃模糊为独立开关；关闭悬浮底栏时必须回退到完整可用的普通导航栏，关闭模糊时仍需保留清晰的实体材质。
- 自定义壁纸必须保留足够的文字对比度；导入异常、文件丢失或 URI 授权失效时应回退到主题背景，不得导致页面崩溃。

## 图标与主视觉

- 当前 Android launcher adaptive icon 使用本地 Vector Drawable，保留现有玉衡青龙标识；在没有经过确认的高质量新稿前不替换。
- 五神兽主体图和主题专属背景目前暂缓，不制作虚假预览图，也不以古画、文物、刺绣、水墨或抽象线条凑数。
- 正式版截图只使用真实设备运行截图；不以设计稿或 UI mockup 冒充实机效果。

## 可读性与无障碍

- 普通正文和辅助文字的色彩对比度以 WCAG AA 4.5:1 为自动化检查门槛。
- 关键状态不能只依赖颜色，还应提供文字、图标或明确的状态说明。
- 检查大字体、小屏、横竖屏、系统安全区、触控区域和滚动遮挡。
- 自动化色彩测试不等于所有页面的真机无障碍验收；禁用态、错误态、壁纸遮罩和动态取色仍需逐项检查。
