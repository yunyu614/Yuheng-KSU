# 玉衡品牌与界面基线

## 品牌定位

- 中文名：玉衡
- 英文名：Yuheng
- 产品定位：个性化 Android Root 管理器
- 品牌关键词：秩序、自由、雅致、温润
- 品牌短句：让 Root 管理，也有东方美学。

## 视觉原则

1. 东方意象作为气质来源，不把传统纹样堆叠到功能界面。
2. 低饱和、柔和层次；浅色界面不使用纯白作为大面积底色。
3. 深色模式独立定义背景、容器、边框和文字层级，不采用简单反色。
4. 信息优先：Root 状态、授权和模块等关键操作必须清晰、可读、易触达。
5. 动效克制；避免持续动画和全屏实时模糊，优先保证低端设备流畅度。

| Token | 初始值 | 用途 |

| background | #E8EFEB | 页面底色 |

| Token | 初始值 | 用途 |
| --- | --- | --- |
| background | #171F1D | 页面底色 |
| surface | #202A26 | 卡片/容器 |
| surfaceVariant | #24312D | 次级容器 |

## 主题命名

- 青瓷雾：默认浅色
- 墨玉：默认深色
- 月白、暖玉、黛紫、玄曜：后续扩展

## 交互与组件

- 卡片圆角建议 18–22dp；按钮 12–16dp。
- 路径、长包名和设备标识默认单行省略，点击后查看完整内容。
- 关键状态同时使用文字/图标表达，不只依赖颜色。
- 列表滚动和页面切换优先使用轻量动画。
- 主题设置持久化需有默认值和版本迁移策略。
